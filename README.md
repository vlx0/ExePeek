# ExePeek

**Карточка EXE или DLL без запуска.** Версия, компания из свойств, архитектура PE и состояние встроенной цифровой подписи.

Автор: **darkshade** ([@vlx0](https://github.com/vlx0)). MIT.

**365 дней open source · неделя 13 — «Софт» · день 86.**

## Возможности

- Разбор PE: тип EXE / DLL, машина x86 / x64 / ARM64 и другие, формат PE32 / PE32+, подсистема.
- Отметка каталога CLR (.NET). Для .NET машина PE и PE32 не определяют однозначно разрядность запуска (AnyCPU).
- Версия файла и продукта, компания, название продукта, описание, исходное имя — если указаны.
- Встроенная Authenticode-подпись через WinVerifyTrust: действительна, отсутствует, повреждена, не прошла проверку доверия либо состояние не установлено.
- Подписант берётся из выбранного Windows сертификата и показывается отдельно от CompanyName из ресурса версии.
- Копирование отчёта, открытие папки расположения файла.
- Чтение в отдельном вспомогательном процессе Python: отмена завершает помощника, ограничение времени — 90 секунд.
- Изменившийся во время проверки файл не выдаёт смешанный результат.
- На время чтения файл открыт с запретом записи и удаления. Если другой процесс уже меняет его, проверка выдаст ошибку доступа вместо смешанных сведений.
- Тёмный русский интерфейс, один экземпляр на сеанс Windows (mutex), stdlib only.

Компания и версия — сведения автора файла, а не доказательство издателя. Подпись не гарантирует отсутствие вредоносного кода. Проверяются только **встроенные** подписи: каталоги Windows не проверяются, поэтому системный файл с каталоговой подписью может не иметь встроенной.

Проверка использует локальные данные и кэш Windows; сетевое получение сертификатов и проверка отзыва отключены. Статус не заменяет свежую онлайн-проверку отзыва. Код Windows и ограничения показаны во вкладке подписи и в отчёте.

Программа не запускает и не загружает исследуемый EXE/DLL. Вспомогательный процесс выполняет только Python-код ExePeek. Не переименовывает, не исправляет и не удаляет файл.

## Запуск

Windows 10+, Python 3.10+ с tkinter. Внешних зависимостей нет.

```powershell
pythonw -m exepeek
```

Либо `start.bat` / `run_exepeek.pyw`. Последний путь сохраняется в `%APPDATA%\ExePeek\settings.json`.
